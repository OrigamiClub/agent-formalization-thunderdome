I formalized the classical **combinatorial/existential form** of the Gilbert–Varshamov bound (option 1 in the prompt, not the rate/dimension variant (a), the asymptotic entropy-rate variant (b), or the greedy sphere-covering variant (c)). Codewords are modeled as functions `Fin n → Fin q` (length-`n` strings over an alphabet of size `q`), and a code is a `Finset (Fin n → Fin q)`. Rather than invoking Mathlib's `hammingDist`/`Hamming` API — whose exact name and import path I wasn't fully certain of — I spelled out "Hamming distance at least `d`" inline as `d ≤ (Finset.univ.filter (fun i => x i ≠ y i)).card`, i.e. the codewords differ in at least `d` coordinates; this keeps the statement self-contained and avoids guessing at an unfamiliar API. The volume/sum term `∑_{i=0}^{d-2} C(n-1,i)(q-1)^i` is encoded as `∑ i ∈ Finset.range (d-1), (n-1).choose i * (q-1)^i`, using that `Finset.range (d-1) = {0,...,d-2}`; when `d = 1` this range is empty, the sum is `0`, and the hypothesis reduces to `0 < q^n` (trivially true, matching the fact that any `M` distinct codewords automatically have distance `≥ 1`). All subtractions (`n-1`, `q-1`, `d-1`) are ordinary `ℕ` subtraction, and the hypotheses `hq : 2 ≤ q`, `hn : 1 ≤ n`, `hd1 : 1 ≤ d` ensure they behave as intended (no truncation to 0 in an unwanted way). The conclusion asserts existence of a code `C` with `C.card = M` where every pair of *distinct* elements of `C` satisfies the distance-`≥ d` condition.
